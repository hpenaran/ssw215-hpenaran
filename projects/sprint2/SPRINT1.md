# SPRINT 1 REPORT

## PROJECT RECAP
This project is a single-user portfolio website for a software engineering student to manage personal projects and showcase their progress, project history, and future plans to visitors such as potential employers. The core workflow is to create a project, save its information, enter a rough project update, click "Polish Update" to generate a concise, polished version using an LLM API, and review the result before displaying it in the project's history.

## WORKFLOW DEMO GUIDE

1. **Open the website:** Open `index.html` in a browser or follow the project's local setup instructions.
2. **Create a project:** Enter a project name, description, GitHub link, current status, and future plans, then submit the form.
3. **Verify the project:** Confirm that the new project appears as a project card with the information you entered.
4. **Add a project update:** Select the project and enter a rough description of the work you completed.
5. **Polish the update:** Click **"Polish Update"** to generate a concise, polished version of your rough update. If the website uses a mock response, verify the simulated polishing behavior.
6. **Review and save:** Review the polished update and save or display it in the project's history.
7. **Verify dynamic updates:** Confirm that the project card and update history change without manually refreshing the page.
8. **Test validation:** Try submitting a project without its required name or polishing an empty update. Confirm that the website prevents invalid submissions and displays an appropriate message.
9. **Check the portfolio:** Review the main current project, recent updates, and future plans to confirm that the information is displayed correctly.

## AI Usage Log & Reflection
I used AI throughout the development of my website to help design and improve the user interface. I used it to choose a color scheme that gives the website a professional and cohesive appearance, as well as to edit grammar and improve the wording of the text displayed on the page. I also used AI to make changes to the website's layout, structure, and overall style, including adjusting the appearance of project cards, buttons, and other elements. These suggestions helped me refine the design and make the website more visually appealing and easier to navigate. I reviewed the changes to ensure they matched my vision for the project and helped me create a website that effectively showcases my personal projects.
